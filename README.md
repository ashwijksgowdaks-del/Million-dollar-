# 💹 TradeX – Smart Trading Platform

TradeX is a modern, AI-ready trading platform built to automate and simplify trading across multiple markets.  
It offers real-time data, customizable strategies, and a clean, responsive dashboard.

---

## 🚀 Features

- 📈 **Live Market Data** – Stream real-time prices from multiple exchanges.  
- 🤖 **Automated Trading Bots** – Build and deploy custom trading strategies.  
- 💼 **Portfolio Management** – Track balances, PnL, and performance over time.  
- 🔔 **Smart Alerts** – Get notified about price
